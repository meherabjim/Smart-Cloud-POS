# Smart Cloud POS

Smart Cloud POS is a modern cloud-based Point of Sale and inventory management system designed for retail businesses.

## Live Application

- Live Website: https://smart-cloud-pos.vercel.app
- Backend API: https://smart-cloud-pos.onrender.com

## Main Features

- Sales and profit dashboard
- Product management
- Inventory and stock history
- Point of Sale system
- Invoice generation
- Sales history and reports
- Damaged and spoiled item tracking
- Multi-store management
- User and role management
- Account and system settings

## Technology Stack

### Frontend
- React.js
- Axios
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- REST API
- JWT Authentication

### Database
- TiDB Cloud
- MySQL-compatible database

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: TiDB Cloud

## Demo Access

The live application requires authentication.

Demo access is available on request. Public credentials will be added after a restricted demo account is implemented.

## Security

Environment variables, database passwords, and JWT secrets are not stored in the public repository.
